# Deployment Guide

This guide provides step-by-step instructions for deploying your portfolio website to Vercel.

## Prerequisites

1.  **GitHub Repository:** Your project code should be available in a GitHub repository.
2.  **Vercel Account:** You need a Vercel account (a free Hobby account is sufficient).
3.  **Sanity.io Account:** You need a Sanity.io account with a project created.
4.  **PostgreSQL Database:** You need a PostgreSQL database. You can get one for free from services like Neon, Supabase, or Vercel Postgres.

## Step 1: Get Your Sanity Credentials

1.  Go to your Sanity project dashboard at [sanity.io/manage](https://www.sanity.io/manage).
2.  Find your **Project ID** and **Dataset** name. You will need these for the environment variables.
3.  You may also want to create a read-only API token if you plan to make your dataset private.

## Step 2: Get Your Database Connection String

1.  From your PostgreSQL database provider, get the connection string (URL).
2.  It should look something like this: `postgresql://USER:PASSWORD@HOST:PORT/DATABASE`.

## Step 3: Deploy to Vercel

1.  Log in to your Vercel account.
2.  Click the "Add New..." button and select "Project".
3.  Import the GitHub repository for this project.
4.  Vercel will automatically detect that it's a Next.js project and configure the build settings.
5.  Before deploying, go to the "Environment Variables" section and add the following:

    | Name                          | Value                                         |
    | ----------------------------- | --------------------------------------------- |
    | `DATABASE_URL`                | Your PostgreSQL connection string.            |
    | `NEXT_PUBLIC_SANITY_PROJECT_ID` | Your Sanity Project ID.                       |
    | `NEXT_PUBLIC_SANITY_DATASET`  | Your Sanity Dataset name (e.g., `production`). |
    | `NEXTAUTH_URL`                | The URL of your Vercel deployment.            |
    | `NEXTAUTH_SECRET`             | A secret string generated by you.             |

    *You can generate a `NEXTAUTH_SECRET` by running `openssl rand -hex 32` in your terminal.*

6.  Click "Deploy". Vercel will now build and deploy your project.

## Step 4: Add Your Domain

1.  Once the deployment is successful, you can go to the "Domains" tab in your Vercel project settings to add your custom domain.

## Step 5: Populate Your Content

1.  The GitHub Actions workflow includes a step to install Playwright dependencies (`--with-deps`), which should set up the necessary environment for E2E tests in CI.
2.  Remember to populate your Sanity Studio with content for your projects, awards, etc. You can run the studio locally or deploy it. The Sanity Studio is available at the `/admin` route of your deployed site.

That's it! Your site should now be live.
